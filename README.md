## Quick Walkthrough

**Quick Walkthrough** is a Decky Loader plugin for SteamOS / Steam Deck Gaming Mode that lets you search and read live game walkthroughs right alongside your game without switching to Desktop Mode or an external browser.

### Key Features
- **Automatic Running Game Detection**: Detects your currently active Steam or non-Steam game (plus Steam Rich Presence hints when available) for instant 1-tap walkthrough search.
- **Multi-Source 1-Step Search**: Searches across **IGN Wikis**, **PowerPyx**, **PC Gamer**, **Game8**, **Steam Community Guides**, and **StrategyWiki**, with optional filtering by boss, chapter, or area — plus direct **Web IGN** / **Web Google** quick search buttons.
- **Live Embedded Chromium Reader (QAM & Fullscreen)**:
  - View live guide webpages directly inside the Quick Access Menu (`...`) or expand to Fullscreen (`Read`).
  - Auto-hides top toolbars by default in QAM (`Show toolbar` bar) to maximize reading area.
  - Built-in back/forward/reload navigation, **Zoom** (`65%–130%`), and **Mobile Fit** (`Fit`) toggle.
  - Keeps pages loaded in memory when closing and reopening the Quick Access Menu so you never lose your spot or reload from scratch.
- **Saved Library & Bookmarks**: Bookmark pages and quickly resume recent guides across sessions (`localStorage` + Decky backend storage).
- **Bilingual UI**: Defaults to **English**, with **Vietnamese (`Tiếng Việt`)** selectable in Settings.
- **SteamOS Network Diagnostics**: Built-in connectivity test in Settings to troubleshoot guide sources.
